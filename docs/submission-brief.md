# Prototype/MVP brief (Hack2skill form, max 1024 characters)

Throughline gives supply chain teams one trusted answer. ERP, TMS, WMS, supplier portals, CRM and IoT define KPIs differently: Q3 on-time delivery reads 98.3%, 91.6% or 85.7% depending on the system. We built an industry ontology (Supplier > Part > Plant > Shipment > Order > Customer, with hierarchies and a source-key crosswalk) and encoded it as governed Snowflake semantic views with 9 certified metrics (on-time delivery, fill rate, days of inventory, landed cost and more), each with an owner, version and allowed dimensions. A conversational layer, run through Cortex Code CLI skills, answers only through those metrics: it maps each team's words to the certified definition, refuses uncertified terms, asks when a term is ambiguous, blocks slices the ontology cannot support and masks contract prices by role. Planning, procurement and logistics asking in their own words get the same plan and identical numbers (85.8%). Also served as a web app, REST API and MCP server; 13 automated tests.
